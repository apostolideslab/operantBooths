# Operant Booth Designs

This repository contains 3D-printable designs and supporting files developed for operant behavioral setups in the Apostolides Lab at the University of Michigan.

The repository includes STL files for fabrication, CAD images showing the designs, and photographs of the fabricated components and their use in the experimental setup.

## Designs

### Port Interface

Custom port interface designed for the operant booth.

**Files include:**
- STL file for 3D printing
- CAD/design images
- Photographs of the fabricated component
- Simulation of the component

### Syringe Holder

Custom syringe holder designed for use with the operant behavioral setup.

**Files include:**
- STL file for 3D printing
- CAD/design images
- Photographs of the fabricated component
- Simulation of the component

## Usage

The STL files can be downloaded and imported into compatible slicing software for 3D printing. The accompanying images are provided as references for the CAD design and the fabricated components.
